## Memos 移动端适配修复

最终方案确认：Memos 保持 JSON 驱动的卡片页（`layouts/memos.html`，数据源 `static/data/flomo_memos.json`），展示形态与 Read（微信读书）页一致；此前短暂尝试的 "blog 同款布局 + Hugo 内容页" 方案已全部回退（layouts/memos/、content/memos/*.md 已删除，导出脚本、baseof、hugo.yml 恢复原状）。

### 核心修复（assets/css/weread-theme.css）
- 根因：`.memos-page .weread-layout { grid-template-columns: 200px 1fr; }` 的特异度高于媒体查询里的 `.weread-layout { grid-template-columns: 1fr; }`，媒体查询不提升特异度，导致窄屏下 Memos 页侧栏不塌缩（Read 页正常）。
- 修复：在 `@media (max-width: 860px)` 内显式加 `.memos-page .weread-layout { grid-template-columns: 1fr; }`；在 `@media (max-width: 560px)` 内加 `.memos-page .memos-grid { gap: 12px; }`。
- 教训：给页面级 body class（如 `.memos-page`）写桌面覆盖样式时，必须在对应媒体查询里写同特异度的移动端覆盖。
