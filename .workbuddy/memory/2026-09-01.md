# 2026-09-01

## 修复 GitHub Actions 部署失败（cd: Hugo: No such file or directory）

- 原因：`.github/workflows/export-weread-notes.yml` 假设 Hugo 站点在 `Hugo/` 子目录，但实际仓库根目录即站点根目录（hugo.yml 在根目录）。
- 修正内容（共 4 处）：
  1. Export 步骤删除 `cd Hugo`，改为在仓库根目录直接运行 `python weread_hugo_exporter.py`（脚本默认 site-dir 为 `.`）
  2. git add 路径由 `Hugo/static/data/weread_notes.json Hugo/content/weread/` 改为 `static/data/weread_notes.json content/weread/`
  3. Build 步骤删除 `cd Hugo`
  4. upload-pages-artifact 的 path 由 `Hugo/public` 改为 `public`
- 注意：仓库布局为「Hugo 站点根目录 = 仓库根目录」，后续改 workflow 时不要再引入子目录假设。
